> **Status: Planned** — Forge is not yet implemented. This document describes the target API.

## Vision

Forge extends the `tower` CLI (shipped in `@towerjs/scribe`) with build and deployment commands: compile the app, generate an optimized Dockerfile, scaffold CI, and manage environment variables across platforms.

## Build

```bash
tower build
```

The build pipeline:

1. Typechecks the project
2. Compiles to `./dist/` and copies static assets
3. Runs Vault migrations and generates typed Kysely queries (if Vault is used)
4. Creates a production `package.json` with only runtime dependencies

## Docker

```bash
tower docker init     # generate an optimized Dockerfile
tower docker build    # build the image
tower docker push     # push to a registry
```

## CI/CD

```bash
tower ci init --provider github
# creates .github/workflows/deploy.yml
```

Generated pipelines typically include:

- Install dependencies
- Run linter and type check
- Run tests
- Run `tower build`
- Deploy to the selected platform

## Environment

Forge validates that all required variables (defined in `tower.config.ts`) are present before building:

```bash
tower env check     # validate local env
tower env pull      # download env from the platform
tower env push      # upload env to the platform
```

## Deploy

```bash
tower deploy --provider vercel
```
