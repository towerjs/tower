---
title: 'Workflows'
description: 'Structured multi-step AI processes with typed steps and output.'
---

Workflows provide structured multi-step AI processes. Each step can combine application logic, tool calls, and model prompts, with the result of one step available to the next.

```ts
const summaryWorkflow = workflow({
  steps: [
    {
      name: 'extract',

      execute: async ({ url }) => {
        return extractContent(url)
      },
    },

    {
      name: 'summarize',

      model: 'anthropic:claude-sonnet-4',

      prompt: 'Summarize the following: {extract.content}',
    },

    {
      name: 'translate',

      model: 'openai:gpt-5-mini',

      prompt: 'Translate to French: {summarize.text}',
    },
  ],

  output: 'translate.text',
})
```

Steps reference each other's results with `{stepName.field}` templates. The `output` key selects which step result the workflow returns.

Workflows are designed for:

- document processing
- automation
- background AI tasks
- multi-step business processes

For long-running workflows that should continue after the request ends, see the [Crane](/docs/crane) integration.
