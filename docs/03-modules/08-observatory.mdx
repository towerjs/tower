## Vision

Observatory aims to give every Tower app production-grade observability out of the box — without needing to wire up OpenTelemetry, Prometheus, or Datadog from scratch.

## Logging

Structured, level-based logging with pluggable transports (stdout, files, remote services).

```tsx
import { logger } from "@towerjs/observatory"

logger.info("user signed in", { userId: 42, ip: "::1" })
logger.error("payment failed", { error: err.message })
```

Log levels: `debug`, `info`, `warn`, `error`, `fatal`.

## Metrics

Collect counters, gauges, and histograms. Metrics can be exposed as a Prometheus endpoint or pushed to a collector.

```tsx
import { metrics } from "@towerjs/observatory"

const requestCount = metrics.counter("http_requests_total", {
  labels: ["method", "path"],
})

metrics.histogram("request_duration_ms", { buckets: [5, 10, 50, 100, 500] })

// In middleware
requestCount.inc({ method: req.method, path: req.url })
```

## Health Checks

Expose a standard `/health` endpoint that reports the status of database connections, external services, and custom checks.

```tsx
import { health } from "@towerjs/observatory"

health.check("database", async () => {
  await db.$queryRaw`SELECT 1`
})

health.check("stripe", async () => {
  await stripe.ping()
})
```

The `/health` endpoint returns:

```json
{
  "status": "healthy",
  "checks": {
    "database": { "status": "healthy", "latencyMs": 2 },
    "stripe": { "status": "healthy", "latencyMs": 45 }
  }
}
```

## Tracing

Distributed tracing via OpenTelemetry, with automatic instrumentation for HTTP requests, database queries, and job processing.

```tsx
import { tracer } from "@towerjs/observatory"

const span = tracer.startSpan("process-report")
// ... do work ...
span.end()
```
