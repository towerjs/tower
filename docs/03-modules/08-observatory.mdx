## Vision

Observatory gives every Tower app production-grade observability out of the box: structured logs, metrics, health checks, and tracing through one facade — with pluggable transports.

## Setup

```tsx filename="tower.config.ts"
observatory: {
  logLevel: 'info',
}
```

## Logging

```tsx
import { observatory } from 'towerjs/observatory'

observatory.log.info('user signed in', { userId: 'usr_1' })
observatory.log.error('payment failed', { error: err.message })
```

Levels: `debug`, `info`, `warn`, `error`.

## Metrics

```tsx
const requests = observatory.metrics.counter('http_requests_total', {
  labels: ['method'],
})

requests.inc({ method: 'POST' })

observatory.metrics.histogram('request_duration_ms', {
  buckets: [5, 10, 50, 100, 500],
})
```

## Health checks

```tsx
observatory.health.check('database', async () => {
  await vault.db.selectFrom('users').select('id').limit(1).execute()
})

observatory.health.check('stripe', async () => {
  await stripe.ping()
})
```

```tsx filename="app/health/route.ts"
import { observatory } from 'towerjs/observatory/next'

export const GET = observatory.health.GET
```

The endpoint returns:

```json
{
  "status": "healthy",
  "checks": {
    "database": { "status": "healthy", "latencyMs": 2 },
    "stripe": { "status": "healthy", "latencyMs": 45 }
  }
}
```

## Tracing

```tsx
const span = observatory.trace.startSpan('process-report')
// ... work ...
span.end()
```
