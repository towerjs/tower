## Vision

Compass makes search a first-class Tower feature. Declare an index in config, and Compass keeps it in sync with Vault — then query with ranked full-text results, facets, and suggestions. The default provider uses Postgres `tsvector`; no separate search service needed.

## Setup

```ts filename="tower.config.ts"
compass: {
  provider: 'postgres',
  indexes: {
    posts: {
      fields: {
        title: { weight: 10 },
        body: { weight: 5 },
        tags: { type: 'array' },
        published: { filterable: true },
      },
    },
  },
}
```

## Providers

| Provider      | Full-text        | Facets | Relevance |
| ------------- | ---------------- | ------ | --------- |
| `postgres`    | tsvector/tsquery | ✓      | `ts_rank` |
| `meilisearch` | ✓                | ✓      | ✓         |
| `typesense`   | ✓                | ✓      | ✓         |

## Synchronization

Indexes stay in sync with Vault automatically through internal events (`vault:record:*`). Backfill existing rows explicitly:

```ts
import { compass } from 'towerjs/compass'

await compass.sync('posts')
```

## Searching

```ts
const { hits, facets, total } = await compass.search('posts', {
  query: 'getting started with tower',
  filters: { published: true },
  facets: ['tags'],
  limit: 20,
  offset: 0,
})

const suggestions = await compass.suggest('posts', 'getti')
```

## Integration with Tower

- **Vault** — indexes reference Vault tables; incremental sync via internal events
- **Beacon** — stream search results or trigger reindex events to clients
