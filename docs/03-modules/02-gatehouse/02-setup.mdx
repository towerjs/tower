Get authentication running end to end: enable the module, mount the API, migrate, and sign in your first user.

## 1. Enable the module

Add `gatehouse` to `tower.config.ts`. Credentials and email verification are good defaults to start with:

```tsx filename="tower.config.ts"
gatehouse: {
  provider: 'better-auth',
  appName: 'My App',
  credentials: { enabled: true },
  emailVerification: { sendOnSignUp: true, autoSignInAfterVerification: true },
}
```

## 2. Set environment variables

```bash
# Optional — your app's base URL. Set `baseURL` in tower.config.ts, or use the
# GATEHOUSE_URL / BETTER_AUTH_URL env fallbacks (development defaults to http://localhost:3000).

# Signs session cookies. Generate with:
# openssl rand -base64 32
# GATEHOUSE_SECRET (or the BETTER_AUTH_SECRET alias) — dev lacks a value, a fallback applies.
BETTER_AUTH_SECRET=your-secret
```

Social provider credentials (`GOOGLE_CLIENT_ID`, `GITHUB_CLIENT_ID`, etc.) are picked up automatically from the environment when you enable social login.

## 3. Mount the auth API

The framework adapter ships the route handlers — mount them where your framework expects:

```tsx filename="app/api/auth/[...all]/route.ts"
import { GET, POST } from 'towerjs/gatehouse/next'

export { GET, POST }
```

This mounts the full Better Auth API under `/api/auth` — the `gatehouseClient` in your browser code talks to it.

## 4. Run migrations

The auth tables (users, sessions, accounts, organizations, ...) live in the Vault database:

```tsx filename="scripts/migrate.ts"
import { initTower } from 'towerjs/runtime'
import { Gatehouse } from '@towerjs/gatehouse'

async function main() {
  const tower = await initTower()
  await Gatehouse.migrate()
  await tower.shutdown()
}

main()
```

```bash
npx tsx scripts/migrate.ts
```

## 5. Create your first user

Sign up through the client — or from the server:

```tsx
import { gatehouseClient } from 'towerjs/gatehouse/client'

await gatehouseClient.signUp.email({
  name: 'Ada',
  email: 'ada@example.com',
  password: 'password123',
})
```

## 6. Protect routes and verify

Route access belongs in the proxy middleware — see [Protected Routes](/docs/gatehouse/protected-routes):

```tsx filename="src/proxy.ts"
import { gatehouse } from '@towerjs/gatehouse'

const { handler } = gatehouse.proxy({
  public: ['/', '/sign-in', '/sign-up'],
  redirectTo: '/sign-in',
})

export const proxy = handler

export const config = {
  matcher: ['/((?!_next/static|favicon.ico|api/auth).*)'],
}
```

Signed-out visitors are redirected to `/sign-in` before any page renders. The session read in your dashboard then just works:

```tsx filename="app/dashboard/page.tsx"
import { gatehouse } from 'towerjs/gatehouse'

export default async function Dashboard() {
  const user = await gatehouse.requireUser()

  return <h1>Welcome, {user.name}</h1>
}
```
