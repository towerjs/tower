---
title: 'Passkeys'
description: 'Passwordless WebAuthn sign-in with device-bound keys.'
---

Passkeys replace passwords with WebAuthn credentials stored on the user's device — Touch ID, Face ID, Windows Hello, or a security key. There's nothing to remember and nothing to phish.

## Enable

```ts
import { gatehouse } from '@towerjs/gatehouse'

gatehouse({
  provider: 'better-auth',
  appName: 'My App',
  passkeys: true,
})
```

## Register a passkey

Passkey registration is a WebAuthn ceremony driven from a signed-in context. Generate the registration options server-side, run the ceremony in the browser, then verify the credential:

```ts filename="src/app/settings/passkeys/actions.ts"
'use server'

import { gatehouse } from '@towerjs/gatehouse'

export async function generateRegistrationOptions() {
  return gatehouse.passkeys.generateRegistrationOptions()
}

export async function verifyRegistration(response: Record<string, unknown>) {
  return gatehouse.passkeys.verifyRegistration({ response })
}
```

```tsx filename="src/app/settings/passkeys/register-passkey.tsx"
'use client'

import { generateRegistrationOptions, verifyRegistration } from '@/app/settings/passkeys/actions'

export function RegisterPasskey() {
  async function handleRegister() {
    const opts = await generateRegistrationOptions()
    const credential = await navigator.credentials.create({ publicKey: opts })
    await verifyRegistration(credential)
  }
  return <button onClick={handleRegister}>Add passkey</button>
}
```

The ceremony methods — `generateRegistrationOptions`, `verifyRegistration`, `generateAuthenticationOptions`, `verifyAuthentication` — handle the WebAuthn flow as typed `passkeys.*` operations. `verifyRegistration` returns the created passkey; it requires an existing session.

## Sign in with a passkey

Passkey sign-in runs the WebAuthn ceremony in the browser: `generateAuthenticationOptions` returns the request options, and `verifyAuthentication` verifies the credential and returns the new `{ user, session }`:

```ts
import { gatehouse } from '@towerjs/gatehouse'

const opts = await gatehouse.passkeys.generateAuthenticationOptions()

// The options come back as WebAuthn JSON — decode them for the browser API.
const publicKey = PublicKeyCredential.parseRequestOptionsFromJSON(
  opts as unknown as PublicKeyCredentialRequestOptionsJSON
)
const credential = await navigator.credentials.get({ publicKey })

const { user, session } = await gatehouse.passkeys.verifyAuthentication({
  response: credential as unknown as Record<string, unknown>,
})
```

## Manage passkeys

List, rename, and remove from the server:

```ts
import { gatehouse } from '@towerjs/gatehouse'

await gatehouse.passkeys.list() // [{ id, name, createdAt }]
await gatehouse.passkeys.update('psk_123', { name: 'MacBook Touch ID' })
await gatehouse.passkeys.delete('psk_123')
```

Actions: `updatePasskey` (`id`, `name`), `deletePasskey` (`id`).

## Notes

- Users must already have a session to register a passkey — pair with email/password or magic links for first sign-in
- Passkeys are device-bound, not syncable — users should register more than one
