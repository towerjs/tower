Users manage their own profile from the account API; admins manage everyone from the admin API.

## Profile

```ts
import { gatehouse } from '@towerjs/gatehouse'

await gatehouse.account.update({ name: 'Ada Lovelace', image: null })
await gatehouse.user() // updated user
```

Action: `updateProfile` (`name`).

## Change email

```ts
import { gatehouse } from '@towerjs/gatehouse'

await gatehouse.account.changeEmail('ada@example.com')
```

With `user.changeEmail.enabled`, the new address must be confirmed before it takes effect.

## Change password

```ts
import { gatehouse } from '@towerjs/gatehouse'

await gatehouse.password.change({ currentPassword: 'old-password', newPassword: 'new-password' })
await gatehouse.password.confirm({ password: 'new-password' }) // boolean — verify before sensitive actions
```

Actions: `changePassword` (`currentPassword`, `newPassword`), `verifyPassword` (`password`).

## Delete account

```ts
import { gatehouse } from '@towerjs/gatehouse'

await gatehouse.account.delete()
```

The `deleteAccount` action requires the current `password` — destructive operations re-authenticate first. Configure cleanup hooks:

```ts
import { gatehouse } from '@towerjs/gatehouse'

gatehouse({
  provider: 'better-auth',
  user: {
    deleteUser: {
      enabled: true,
      beforeDelete: async (user) => {
        console.log('deleting', user.id)
      },
      afterDelete: async (user) => {
        console.log('deleted', user.id)
      },
    },
  },
})
```

## Admin API

Enable it, then manage users from your admin UI:

```ts
import { gatehouse } from '@towerjs/gatehouse'

gatehouse({
  provider: 'better-auth',
  admin: true,
})
```

```ts
import { gatehouse } from '@towerjs/gatehouse'

const userId = 'usr_123'

await gatehouse.admin.listUsers({ searchField: 'email', searchValue: 'ada@' })
// { users, total }

await gatehouse.admin.getUser(userId)
await gatehouse.admin.removeUser(userId)
await gatehouse.admin.setUserPassword(userId, 'new-password')
await gatehouse.admin.setRole({ userId, role: 'admin' })
```

### Banning

```ts
import { gatehouse } from '@towerjs/gatehouse'

const userId = 'usr_123'

await gatehouse.admin.banUser(userId, {
  banReason: 'Spam',
  banExpiresIn: 7 * 86400, // seconds; omit for permanent
})
await gatehouse.admin.unbanUser(userId)
```

Banned users are blocked at sign-in and lose their sessions. `user.banned` / `user.banReason` surface the state (`banExpiresAt` is not mapped by the adapter).

### Impersonation

```ts
import { gatehouse } from '@towerjs/gatehouse'

const userId = 'usr_123'

await gatehouse.admin.impersonateUser(userId)
await gatehouse.admin.stopImpersonating()
```

Impersonation shows up as `session.impersonatedBy` on the impersonated session — check it to show a banner in your UI.

### Sessions & permissions

```ts
import { gatehouse } from '@towerjs/gatehouse'

const userId = 'usr_123'
const sessionToken = 'ses_456'

await gatehouse.admin.listUserSessions(userId)
await gatehouse.admin.revokeUserSession(sessionToken)
await gatehouse.admin.revokeUserSessions(userId)
```

Role and permission checks live on the authorization API — see [Authorization](/docs/gatehouse/authorization).

## User fields

`GatehouseUser` carries: `id`, `name`, `email`, `emailVerified`, `image`, `createdAt`, `updatedAt`, plus `twoFactorEnabled`, `banned` / `banReason`, and `role` when enabled. Add your own columns with `user.additionalFields`.
