---
title: 'Actions'
description: 'Pre-built server actions: wire auth straight into forms with no client code.'
---

Gatehouse ships pre-built server actions for common auth operations. They run in an authenticated request context, take plain form fields, and return `{ ok: true }` or `{ error: string }` — ready for `useActionState`.

## Usage

Re-export them from your app's actions module:

```tsx filename="app/actions.ts"
'use server'

export {
  signIn,
  signUp,
  signOut,
  updateProfile,
  changePassword,
  createOrganization,
  inviteMember,
  // ...any of the actions below
} from 'towerjs/gatehouse/actions'
```

```tsx filename="app/sign-in/sign-in-form.tsx"
'use client'

import { useActionState } from 'react'
import { signIn } from '@/app/actions'

export function SignInForm() {
  const [state, action, pending] = useActionState(signIn, undefined)

  return (
    <form action={action}>
      {state?.error && <p role="alert">{state.error}</p>}
      <input name="email" type="email" required />
      <input name="password" type="password" required />
      <button type="submit" disabled={pending}>
        Sign in
      </button>
    </form>
  )
}
```

Field names map directly to `<input name="...">` attributes.

## Error handling

Actions wrapped with `action.form` return `{ error: string }` on failure and `{ ok: true }` on success — render `state.error` in the form; no try/catch needed.

A few actions are wrapped with plain `action()` instead and **throw** on failure rather than returning `{ error }`: `enableTwoFactor` and `generateBackupCodes` return their data (`{ totpURI, backupCodes }` and the new codes) directly and will reject with an error — catch around them.
