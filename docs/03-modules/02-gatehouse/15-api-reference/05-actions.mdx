---
title: "Actions"
description: "50+ pre-built server actions: wire auth straight into forms with no client code."
---

Gatehouse ships pre-built server actions for every auth operation. They run in an authenticated request context, take plain form fields, and return `{ ok: true }` or `{ error: string }` — ready for `useActionState`.

## Usage

Re-export them from your app's actions module:

```tsx filename="app/actions.ts"
'use server'

export {
  signIn, signUp, signOut,
  updateProfile, changePassword,
  createOrganization, inviteMember,
  // ...any of the actions below
} from 'towerjs/gatehouse/actions'
```

```tsx filename="app/sign-in/sign-in-form.tsx"
'use client'

import { useActionState } from 'react'
import { signIn } from '@/app/actions'

export function SignInForm() {
  const [state, action, pending] = useActionState(signIn, undefined)

  return (
    <form action={action}>
      {state?.error && <p role="alert">{state.error}</p>}
      <input name="email" type="email" required />
      <input name="password" type="password" required />
      <button type="submit" disabled={pending}>Sign in</button>
    </form>
  )
}
```

Field names map directly to `<input name="...">` attributes.

## Error handling

Actions return `{ error: string }` on failure and `{ ok: true }` on success (actions that return data — `enableTwoFactor`, `createApiKey`, `generateBackupCodes` — include it in the response). Render `state.error` in the form; no try/catch needed.
