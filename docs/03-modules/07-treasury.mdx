> **Status: Planned** — Treasury is not yet implemented. This document describes the target API.

## Vision

Treasury wraps payment providers behind a stable Tower API. Define plans, create checkout sessions, manage subscriptions, and react to billing events — without payment-provider boilerplate in application code.

## Setup

```tsx filename="tower.config.ts"
treasury: {
  provider: 'stripe',
  secretKey: process.env.STRIPE_SECRET_KEY,
  webhookSecret: process.env.STRIPE_WEBHOOK_SECRET,
  plans: {
    pro: { name: 'Pro', price: 1200, interval: 'monthly' },
    team: { name: 'Team', price: 4900, interval: 'monthly' },
  },
}
```

## Checkout

```tsx
import { treasury } from 'towerjs/treasury'

const session = await treasury.checkout.create({
  customerId: 'org_123',
  plan: 'pro',
  successUrl: '/billing/success',
  cancelUrl: '/billing',
})

// redirect to session.url
```

## Subscriptions

```tsx
const sub = await treasury.subscription.get('sub_123')

await treasury.subscription.change('sub_123', { plan: 'team' })
await treasury.subscription.cancel('sub_123', { atPeriodEnd: true })
await treasury.subscription.resume('sub_123')
```

## Invoices

```tsx
const invoices = await treasury.invoice.list('org_123')
const pdf = await treasury.invoice.download(invoices[0].id)
```

## Webhooks

Treasury registers webhook endpoints and maps provider events to Tower internal events:

```tsx filename="app/api/billing/webhook/route.ts"
import { treasury } from 'towerjs/treasury/next'

export const POST = treasury.webhook
```

```tsx
treasury.on('invoice.paid', async ({ customerId }) => {
  await grantAccess(customerId)
})
```

## Integration with Tower

- **Gatehouse** — subscriptions keyed to organizations (`org_*`)
- **Vault** — store customers and subscription records
- **Observatory** — log checkout failures and webhook errors
