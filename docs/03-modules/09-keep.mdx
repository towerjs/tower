## Vision

Keep abstracts local disk and S3-compatible object storage behind one facade. Swap storage backends with a config change — no code changes needed.

## Setup

```tsx filename="tower.config.ts"
keep: {
  defaultDisk: 'local',
  disks: {
    local: {
      driver: 'local',
      root: './storage',
    },
    prod: {
      driver: 's3',
      bucket: 'my-app-prod',
      region: 'us-east-1',
      accessKeyId: process.env.AWS_ACCESS_KEY_ID,
      secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY,
    },
    r2: {
      driver: 's3',
      bucket: 'my-app',
      endpoint: `https://${process.env.CLOUDFLARE_ACCOUNT_ID}.r2.cloudflarestorage.com`,
    },
  },
}
```

## Storing files

```tsx
import { keep } from 'towerjs/keep'

const file = await keep.storage.put('avatars/user-42.png', buffer, {
  contentType: 'image/png',
})

const data = await keep.storage.get('avatars/user-42.png') // Buffer or stream
await keep.storage.delete('avatars/user-42.png')

// Public URL (requires publicUrl on the disk)
const url = keep.url('avatars/user-42.png')

// Signed URL for private files
const signed = await keep.storage.signedUrl('reports/q3.pdf', {
  expiresIn: 3600,
})
```

## Disks

A **disk** is a named storage configuration. Use a specific disk through the facade:

```tsx
await keep.storage.disk('prod').put('backups/db.sql', buffer)
```

## Providers

| Driver  | Backends                                           |
| ------- | -------------------------------------------------- |
| `local` | Local disk (development)                           |
| `s3`    | AWS S3, Cloudflare R2, MinIO, Garage, Backblaze B2 |
