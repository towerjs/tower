## Vision

Keep abstracts local disk, S3-compatible object storage, and CDN delivery behind a single interface. Swap storage backends with a config change — no code changes needed.

## Upload / Retrieve / Delete

```tsx
import { storage } from "@towerjs/keep"

// Upload
const file = await storage.put("avatars/user-42.png", buffer, {
  contentType: "image/png",
})

// Retrieve (returns a readable stream or buffer)
const data = await storage.get("avatars/user-42.png")

// Delete
await storage.delete("avatars/user-42.png")

// Generate a signed URL (for private files)
const url = await storage.signedUrl("reports/q3.pdf", { expiresIn: 3600 })
```

## Disks

A **disk** is a named storage configuration. You can define multiple disks and use different ones per environment.

```tsx filename="tower.config.ts"
// tower.config.ts
import { defineConfig } from "@towerjs/keep"

export default defineConfig({
  disks: {
    local: {
      driver: "local",
      root: "./storage",
    },
    s3: {
      driver: "s3",
      bucket: "my-app-prod",
      region: "us-east-1",
      endpoint: process.env.S3_ENDPOINT,
    },
    r2: {
      driver: "s3",
      bucket: "my-app",
      endpoint: `https://${process.env.CLOUDFLARE_ACCOUNT_ID}.r2.cloudflarestorage.com`,
    },
  },
})
```

Use a specific disk:

```tsx
const avatar = storage.disk("s3").put("...", buffer)
```

## Object Storage

Keep works with any S3-compatible provider: AWS S3, Cloudflare R2, MinIO, Garage, Backblaze B2.
