---
title: "CLI Reference"
description: "The tower command-line interface for database migrations, seeding, and project management."
---

The Tower CLI ships with the `@towerjs/scribe` package, so any project that installed it — or was scaffolded with `tower create` — gets the `tower` binary.

```bash
npx tower <command> [options]
```

## Commands

### migrate

Run database migrations:

```bash
npx tower migrate
npx tower migrate --seed    # Run migrations, then seed data
npx tower migrate -s        # Shorthand for --seed
```

Runs all pending Kysely migrations for both Vault and Gatehouse auth tables.

### seed

Run seed files:

```bash
npx tower seed                     # Run migrations first, then seeds
npx tower seed --skip-migrate      # Seeds only
```

Seed files live in `src/vault/seeds/`.

### --version / -v

```bash
npx tower --version
# → tower/0.1.0
```

### help

```bash
npx tower help
```

## Scaffolding

```bash
pnpm create tower
```

This uses `@towerjs/scribe` to scaffold a new project interactively.
