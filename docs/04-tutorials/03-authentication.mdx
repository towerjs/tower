This tutorial walks through setting up authentication in a Tower + Next.js application.

## 1. Configure Gatehouse

```ts filename="tower.config.ts"
import { defineTower } from '@towerjs/tower/blueprint'

export default defineTower({
  modules: {
    vault: {},
    courier: { email: { provider: 'console', from: 'noreply@example.com' } },
    gatehouse: {
      provider: 'better-auth',
      appName: 'My App',
      baseURL: 'http://localhost:3000',

      credentials: { enabled: true },
      emailVerification: { sendOnSignUp: true, autoSignInAfterVerification: true },
      social: { google: {}, github: {} },
      magicLinks: true,
    },
  },
})
```

Courier is auto-wired — Gatehouse uses it for password reset, email verification, and magic link emails automatically.

> **Social provider env vars** — enabling a social provider requires its credentials in the environment (`GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET`); Gatehouse throws at startup if they're missing.

## 2. Set up Auth Infrastructure

Create the required files:

```ts filename="src/proxy.ts"
import { gatehouse } from '@towerjs/gatehouse'

const { handler } = gatehouse.proxy({
  public: ['/', '/sign-in', '/sign-up'],
  redirectIfAuthenticated: ['/sign-in', '/sign-up'],
  redirectTo: '/sign-in',
  redirectAfterSignIn: '/dashboard',
})
export const proxy = handler
export const config = { matcher: ['/((?!_next/static|favicon.ico|api/auth).*)'] }
```

```ts filename="src/app/api/auth/[...all]/route.ts"
export { GET, POST } from '@towerjs/tower/gatehouse/next'
```

Import the pre-built auth actions directly from `@towerjs/tower/gatehouse/actions` in your client components — do not create a `src/actions.ts` re-export wrapper (Turbopack cannot verify that re-exported values from a `'use server'` module are async, which breaks `next build`):

```tsx filename="src/app/sign-in/sign-in-form.tsx"
'use client'

import { signIn } from '@towerjs/tower/gatehouse/actions'

import { useActionState } from 'react'

export function SignInForm() {
  const [state, action, pending] = useActionState(signIn, undefined)

  return (
    <form action={action}>
      {state?.error && <p role="alert">{state.error}</p>}
      <input name="email" type="email" placeholder="Email" required />
      <input name="password" type="password" placeholder="Password" required />
      <button type="submit" disabled={pending}>
        Sign In
      </button>
    </form>
  )
}
```

## 5. Protected Dashboard

```tsx filename="src/app/dashboard/page.tsx"
import { gatehouse } from '@towerjs/tower/gatehouse'
import { signOut } from '@towerjs/tower/gatehouse/actions'

import { redirect } from 'next/navigation'

export default async function Dashboard() {
  const session = await gatehouse.getSession()
  if (!session) redirect('/sign-in')

  return (
    <div>
      <h1>Welcome, {session.user.name}</h1>
      <form action={signOut}>
        <button type="submit">Sign Out</button>
      </form>
    </div>
  )
}
```

## 6. Using Organizations

```tsx filename="src/app/dashboard/organizations/page.tsx"
import { gatehouse } from '@towerjs/tower/gatehouse'

export default async function OrganizationsPage() {
  const orgs = await gatehouse.getOrganizations()

  return (
    <ul>
      {orgs.map((org) => (
        <li key={org.id}>{org.name}</li>
      ))}
    </ul>
  )
}
```

## 7. Two-Factor Auth

Enable in config:

```ts
twoFactor: true,
```

Then in your app:

```ts
import { enableTwoFactor, verifyTwoFactor } from '@towerjs/tower/gatehouse/actions'

// In a settings page:
const result = await enableTwoFactor(new FormData()) // shows QR code
await verifyTwoFactor(new FormData()) // completes setup
```
